# М3 «Полёт на Марс»

Программа численно моделирует вертикальный взлёт с Земли, пассивный
перелёт в поле Солнца и торможение до мягкой посадки на Марс.

## Запуск

Нужен Python 3.11 или новее. Из папки с этим README:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m mars_flight
```

На Windows команда активации окружения: `.venv\Scripts\activate`.
Программа выводит численные результаты и сохраняет графики и применённые
параметры в новой папке `results/`. При наличии графического интерфейса
она также открывает графики. Для запуска без окон используйте
`MPLBACKEND=Agg python -m mars_flight`.

Исходные параметры и допуски задаются в `mars_flight/config.py`.
Краткий отчёт с изменением параметров, сравнением с аналитическими
решениями и графиком номинального перелёта находится в
[report/report.md](report/report.md).

## Вклад авторов

- **Кашков Сергей** — численная модель перелёта от орбиты Земли
  до орбиты Марса (`transfer.py`), модель торможения и посадки (`mars.py`)
  и соединение этапов с переводом скоростей между системами отсчёта
  (`mission.py`); параметры этих этапов в `config.py`.
- **Богославский Родион** — расчёт перехода Гомана (`theory.py`)
  и модель взлёта с Земли (`earth.py`); построение графиков (`plots.py`),
  вывод результатов и сохранение файлов (`__main__.py`), параметры взлёта
  в `config.py`.
