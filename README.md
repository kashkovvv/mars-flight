# М3 «Полёт на Марс»

Учебная модель полёта космического корабля с Земли на Марс. Численно
рассчитываются вертикальный взлёт, пассивный перелёт в поле Солнца и
торможение до мягкой посадки на Марс. Переход Гомана служит аналитическим
ориентиром.

Корабль считается материальной точкой; атмосфера и вращение планет не
учитываются. Этапы соединяются приближением сфер влияния. В точке окончания
солнечного участка предполагаются встреча с Марсом и радиальное сближение
для посадки; положение Марса во времени не рассчитывается. Этапы связывает
`MissionModel` в `mars_flight/mission.py`. Подробнее:
[математическая модель](docs/model.md).

## Установка

Требуется Python 3.11 или новее. Рабочие зависимости: NumPy, SciPy и Matplotlib.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Для проверки типов и стиля установите дополнительные зависимости:

```bash
python -m pip install -r requirements-dev.txt
```

## Запуск и проверки

```bash
python -m mars_flight
python -m unittest discover -s tests -v
python -m mypy mars_flight tests report
python -m flake8 mars_flight tests report
python -m compileall -q mars_flight tests report
```

При каждом запуске программа выводит результаты, строит графики в Matplotlib,
сохраняет их в отдельную папку `results/ГГГГ-ММ-ДД_ЧЧ-ММ-СС_микросекунды/`
и открывает фигуры на экране. Закройте окна с графиками, чтобы завершить
программу. В папке запуска находятся `ascent.png` и `landing.png`
(высота, скорость, масса и тяга по времени работы двигателя), `transfer.png`
(траектория, радиус и скорость) и `parameters.json` со значениями
конфигурации. Папка `results/` исключена из Git. В среде без графического
интерфейса можно использовать `MPLBACKEND=Agg python -m mars_flight`: PNG
сохранятся, но окна не откроются.

Тесты проверяют сохранение энергии на участках без тяги, расход топлива,
ограничение перегрузки, передачу результатов между этапами и конечную
скорость посадки.

Все входные параметры находятся в `mars_flight/config.py`. Расчёты ведутся
в СИ; преобразование единиц выполняется только для вывода.
