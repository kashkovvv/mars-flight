# М3 «Полёт на Марс»

Учебная модель полёта космического корабля с Земли на Марс. Сейчас
реализованы аналитический расчёт перелёта Гомана и численное моделирование
вертикального взлёта до необходимой энергии ухода из поля Земли.
Численный перелёт в поле Солнца и мягкая посадка на Марс пока не реализованы.

Корабль считается материальной точкой; атмосфера и вращение планет не
учитываются. Переход от конечного состояния взлёта к гелиоцентрическому
движению использует приближение сфер влияния. Подробнее:
[математическая модель](docs/model.md).

## Установка

Требуется Python 3.11 или новее. Рабочие зависимости: NumPy и SciPy.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Для проверки типов и стиля установите дополнительные зависимости:

```bash
python -m pip install -r requirements-dev.txt
```

## Запуск и проверки

```bash
python -m mars_flight
python -m unittest discover -s tests -v
python -m mypy mars_flight tests
python -m flake8 mars_flight tests
python -m compileall -q mars_flight tests
```

Запуск выводит скорости и время аналитического перехода, а также результат
взлёта: длительность, высоту, радиальную скорость, массу и максимальную
перегрузку. Все входные параметры находятся в `mars_flight/config.py`;
внутри расчётов используются единицы СИ, преобразование выполняется только
для вывода.
