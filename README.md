# М3 «Полёт на Марс»

Численная модель полёта космического корабля с Земли на Марс:

1. вертикальный взлёт с поверхности Земли;
2. пассивный перелёт в поле тяготения Солнца;
3. торможение и мягкая посадка на Марс.

Модель использует приближение материальной точки. Атмосфера и вращение
планет не учитываются. На межпланетном участке не учитывается притяжение
планет.

## Требования

- Python 3.11 или новее.

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Запуск

```bash
python -m mars_flight
```

## Тесты

```bash
python -m unittest discover -s tests -v
```

## Конфигурация

Входные параметры задаются в `mars_flight/config.py`. Все расчёты выполняются
в СИ; преобразование единиц используется только при выводе результатов.
