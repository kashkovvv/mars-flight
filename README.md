# М3 «Полёт на Марс»

Учебная модель полёта космического корабля с Земли на Марс. Реализованы
численный вертикальный взлёт, численный пассивный перелёт в поле Солнца и
аналитический ориентир — переход Гомана. Торможение и мягкая посадка на Марс
пока не реализованы.

Корабль считается материальной точкой; атмосфера и вращение планет не
учитываются. Передача скорости из земной системы отсчёта в
гелиоцентрическую использует приближение сфер влияния. Численный перелёт
заканчивается на противоположной стороне солнечной орбиты; программа
показывает отличие этого радиуса от радиуса орбиты Марса. Подробнее:
[математическая модель](docs/model.md).

## Установка

Требуется Python 3.11 или новее. Рабочие зависимости: NumPy и SciPy.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Для проверки типов и стиля установите дополнительные зависимости:

```bash
python -m pip install -r requirements-dev.txt
```

## Запуск и проверки

```bash
python -m mars_flight
python -m unittest discover -s tests -v
python -m mypy mars_flight tests
python -m flake8 mars_flight tests
python -m compileall -q mars_flight tests
```

Запуск выводит аналитические параметры перехода, результат взлёта и
численного перелёта. Тесты сравнивают численный перелёт с переходом Гомана
и проверяют сохранение энергии и момента импульса в поле Солнца.

Все входные параметры находятся в `mars_flight/config.py`. Расчёты ведутся
в СИ; преобразование единиц выполняется только для вывода.
