# `tests/test_mars.py`

## Назначение

Тесты проверяют модель посадки вместе с фактическими результатами взлёта и
солнечного перелёта. Скорость относительно Марса вычисляется из радиальной
и касательной компонент численной траектории.

## Проверки

- Поля `MarsLandingParameters` конечны и положительны; начальный радиус
  больше радиуса Марса, относительный допуск меньше единицы, шаги не
  превышают доступное время.
- При стандартных параметрах скорость обнуляется у поверхности, масса
  остаётся больше сухой и перегрузка не превышает 3 $g_0$.
- На участке без тяги масса и удельная энергия постоянны.
- Убывание массы при торможении согласуется с аналитическим решением
  уравнения расхода топлива. Более высокая скорость подлёта требует
  более раннего включения двигателя и оставляет меньше топлива.
- Недопустимые скорости и массы, недостаточная тяга или высота,
  недостаточный запас топлива и короткий предел времени дают явные ошибки.
- Отдельный случай с сухой массой 20 т подтверждает недостаток топлива
  при прежнем стандартном параметре.

`setUpClass()` один раз создаёт результаты предыдущих этапов для всех
проверок. `dataclasses.replace()` изменяет отдельный параметр
неизменяемого стандартного объекта; `subTest()` отмечает каждый
недопустимый вход. Физические уравнения описаны в
[теории посадки](../mars_landing.md).
