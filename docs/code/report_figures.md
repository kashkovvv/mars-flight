# `report/generate_figures.py`

## Назначение

Скрипт воспроизводит два рисунка расчётных экспериментов из
[краткого отчёта](../../report/report.md). Файлы сохраняются в
`report/figures/`: `solar_transfer_sensitivity.png` и
`mars_descent_sensitivity.png`. Скрипт не меняет рисунки отдельных запусков
в `results/` и не открывает графические окна.

## Расчёты

`main()` берёт стандартные параметры из `mars_flight/config.py`.
Для солнечного опыта целевая скорость ухода от Земли принимает 95, 100
и 105 % значения перехода Гомана. Для каждого варианта рассчитывается
земной взлёт; фактическая удельная энергия на его конце задаёт скорость
для `SolarTransferModel`. Первая фигура показывает три численные
траектории и отклонение конечного радиуса от радиуса орбиты Марса.

Для марсианского опыта сначала рассчитывается номинальная миссия через
`MissionModel`. Затем начальная скорость марсианского снижения принимает
95, 100 и 105 % её номинального значения, а масса после земного взлёта
остаётся одной и той же. Вторая фигура показывает скорость снижения и
полную массу корабля в зависимости от высоты во время работы двигателя.
Это отдельная проверка чувствительности модели посадки, а не продолжение
изменённых солнечных траекторий.

## Запуск

Из корня проекта после установки зависимостей:

```bash
MPLBACKEND=Agg python -m report.generate_figures
```

Matplotlib строит графики, NumPy формирует массивы точек орбит и обрабатывает
численные истории. `_save()` сохраняет PNG с разрешением 180 dpi и закрывает
фигуру. Цвета и подписи вариантов общие для обоих рисунков.
