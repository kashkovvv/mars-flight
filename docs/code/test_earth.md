# `tests/test_earth.py`

## Назначение

Тесты разделены по проверяемым классам.

## `EarthAscentParametersTests`

Проверяет создание и валидацию `EarthAscentParameters`:

- все числовые поля должны быть конечными и положительными;
- сухая масса должна быть меньше начальной;
- относительная погрешность должна быть меньше единицы;
- максимальный шаг не должен превышать время расчёта;
- начальной тяги должно хватать для отрыва от Земли.

## `EarthAscentModelTests`

Проверяет численную модель взлёта и обработку неудачного расчёта.

Проверяются:

- отклонение недопустимой целевой скорости;
- достижение требуемой удельной энергии;
- соблюдение ограничения перегрузки;
- совпадение численной массы с аналитическим кусочным законом;
- согласованность скорости с формулой Циолковского и интегралом потерь на
  тяготение;
- расчёт перегрузки по тяге без вычитания земного притяжения;
- контрольные значения стандартного расчёта;
- явная ошибка при переполнении целевой энергии, исчерпании топлива или
  достижении предельного времени до цели.

Формулы для проверок приведены в документе
[«Вертикальный взлёт с Земли»](../earth_ascent.md).

## Организация тестов

Метод `setUp()` класса `EarthAscentModelTests` выполняется перед каждым
тестом и создаёт новый объект модели и новый результат. Поэтому тесты не
используют изменённое состояние друг друга.

`dataclasses.replace()` создаёт новый набор параметров, заменяя только
указанное поле. Исходный неизменяемый объект параметров остаётся прежним.

`assertAlmostEqual(..., delta=...)` сравнивает отдельные контрольные числа с
заданной абсолютной погрешностью. `numpy.testing.assert_allclose()` сравнивает
сразу всю численную историю массы с аналитическим решением, используя
относительную и абсолютную погрешности.

`assertRaisesRegex()` проверяет не только тип исключения, но и часть его
сообщения. Так тест отличает ожидаемое исчерпание топлива от другой ошибки
расчёта.
