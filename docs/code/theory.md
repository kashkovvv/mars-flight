# `mars_flight/theory.py`

## Назначение

Модуль рассчитывает аналитический перелёт Гомана. Результат используется как
ориентир для последующей проверки численного решения.

## `HohmannTransfer`

Неизменяемый результат расчёта:

| Поле | Смысл | Единица |
|---|---|---:|
| `semi_major_axis_m` | большая полуось переходного эллипса | м |
| `earth_orbital_speed_m_s` | модуль орбитальной скорости Земли | м/с |
| `mars_orbital_speed_m_s` | модуль орбитальной скорости Марса | м/с |
| `departure_heliocentric_speed_m_s` | скорость корабля у орбиты Земли относительно Солнца | м/с |
| `arrival_heliocentric_speed_m_s` | скорость корабля у орбиты Марса относительно Солнца | м/с |
| `departure_excess_speed_m_s` | модуль скорости $v_{\infty,E}$ относительно Земли | м/с |
| `arrival_relative_velocity_m_s` | проекция скорости относительно Марса на направление его движения | м/с |
| `arrival_relative_speed_m_s` | модуль скорости относительно Марса | м/с |
| `time_of_flight_s` | время перелёта | с |

Поля с `speed` в имени хранят неотрицательные модули. Поле с `velocity`
хранит знаковую проекцию на направление движения Марса.

## Расчёт

Метод

```python
HohmannTransfer.from_parameters(parameters)
```

принимает проверенный объект `MissionParameters` и возвращает заполненный
объект `HohmannTransfer`. Это альтернативный конструктор: он выполняет
расчёт до создания результата и не изменяет входные параметры.

Формулы и их краткий вывод приведены в документе
[«Аналитический перелёт Гомана»](../hohmann_transfer.md). Правила перехода
между системами отсчёта приведены в [описании модели](../model.md).
