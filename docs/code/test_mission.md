# `tests/test_mission.py`

## Назначение

Интеграционный тест `test_connects_stage_results()` запускает миссию с
параметрами по умолчанию и проверяет величины, передаваемые через границы
этапов: скорость ухода из конечной удельной энергии взлёта, начальную
гелиоцентрическую скорость, скорость подлёта относительно Марса и массу в
начале посадки. Так проверяется именно соединение расчётов в
[`mission.py`](mission.md).

`test_rejects_radius_miss_before_landing()` подменяет результат солнечной
модели и проверяет, что при слишком большом отклонении радиуса в обе
стороны или неконечном значении посадка не запускается.

`test_rejects_invalid_orbit_match_tolerance()` проверяет отклонение
отрицательного, `NaN` и бесконечного допусков. `subTest()` показывает
конкретное ошибочное значение, если одна из проверок перестанет проходить.
