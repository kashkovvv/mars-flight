# `mars_flight/mars.py`

## Назначение

Модуль рассчитывает радиальное свободное падение к Марсу и последующее
торможение двигателем до почти нулевой скорости у поверхности. Физические
допущения и вывод высоты включения двигателя приведены в
[теории посадки](../mars_landing.md).

## `MarsLandingResult`

`@dataclass(frozen=True)` хранит историю в единицах СИ. Для историй
используются `NDArray[np.float64]`: фиксированный тип массива делает
вычисления и проверки типов явными. Замороженный контейнер запрещает
переназначать его поля, но не делает сами массивы неизменяемыми.

| Поле | Смысл | Единица |
|---|---|---:|
| `time_s` | время с начала марсианского участка | с |
| `radius_m`, `altitude_m` | расстояние от центра и высота над поверхностью | м |
| `radial_velocity_m_s` | знаковая скорость, положительная наружу | м/с |
| `mass_kg` | текущая масса | кг |
| `thrust_n` | направленная наружу тяга | Н |
| `load_factor` | перегрузка от тяги в единицах $g_0$ | безразмерная |
| `specific_energy_m2_s2` | удельная механическая энергия в поле Марса | м²/с² |
| `ignition_time_s`, `ignition_altitude_m` | момент и высота включения двигателя | с, м |
| `initial_excess_speed_m_s` | заданный модуль скорости относительно Марса | м/с |

Свойства `duration_s`, `burn_duration_s`, `final_altitude_m`,
`final_radial_velocity_m_s`, `final_mass_kg` и `maximum_load_factor`
возвращают итоговые характеристики.

## `MarsLandingModel.simulate()`

Метод получает неотрицательный модуль скорости подлёта и массу после взлёта.
Он проверяет конечность значений, наличие топлива, достаточность тяги и
высоты. Ускорение от тяги выбирается один раз по начальной массе; при
торможении тяга равна текущей массе, умноженной на это ускорение.

`solve_ivp(method="RK45")` вызывается дважды. На первом участке тяга
нулевая; событие `ignition_event` останавливает интегрирование при
достижении вычисленной высоты включения двигателя. На втором участке
`velocity_zero_event` фиксирует остановку, а `dry_mass_event` —
преждевременное исчерпание топлива. Атрибуты `terminal` и `direction`,
установленные через `setattr()`, задают остановку и направление
пересечения для SciPy. Вложенные функции событий используют параметры,
вычисленные внутри `simulate()`; `lambda` передаёт производным нужное
значение ускорения от тяги.

Массив `atol` задаёт отдельные абсолютные допуски для радиуса, скорости и
массы; `rtol` — общий относительный допуск. Для свободного падения и
торможения установлены разные максимальные шаги. Если интегрирование не
удалось, истекло время, кончилось топливо или скорость обнулилась вдали от
поверхности, вызывается `RuntimeError`.

Истории двух участков соединяются через `np.concatenate()`. Начальная точка
второго участка исключается срезом `[1:]`, чтобы не дублировать момент
включения двигателя. Для этого единственного момента история тяги содержит
значение до переключения; сразу после него тяга положительна.

## `_derivatives()`

Состояние имеет порядок `(radius, radial_velocity, mass)`. Метод возвращает
производные в том же порядке. При нулевом ускорении от тяги масса постоянна,
а удельная энергия сохраняется. При работе двигателя
`thrust_n / (mass_kg * standard_gravity_m_s2)` даёт ощущаемую перегрузку.
