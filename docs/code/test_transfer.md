# `tests/test_transfer.py`

## Назначение

Тесты проверяют параметры решателя, физический смысл численного
перелёта и обработку неудачного расчёта.

## Проверки

- Все поля `TransferIntegrationParameters` должны быть конечными и
  положительными; дополнительно проверяются ограничения `rtol < 1`
  и `maximum_step_s <= maximum_time_s`.
- Начальная гелиоцентрическая скорость получается из фактической
  энергии после взлёта и орбитальной скорости Земли. Радиальная скорость
  в конце взлёта не используется как скорость ухода вдали от Земли.
- Для стандартных параметров время, конечный радиус и скорость
  совпадают с аналитическим [переходом Гомана](../hohmann_transfer.md).
- При нулевой скорости ухода получается круговая орбита радиуса орбиты
  Земли и половина её аналитического периода.
- Солнечная удельная энергия и удельный момент импульса остаются
  постоянными вдоль численной траектории.
- Знаковая касательная скорость относительно Марса отрицательна:
  корабль отстаёт от планеты в направлении её движения.
- При изменении скорости ухода на $\pm5\%$ конечный радиус оказывается
  соответственно ниже и выше орбиты Марса.
- Недопустимые скорости и слишком короткое предельное время вызывают
  явные исключения.

`setUp()` создаёт свежие модель и результат для каждого теста.
`dataclasses.replace()` позволяет изменять один параметр без
изменения стандартного неизменяемого объекта.
`subTest()` помечает отдельные недопустимые значения.
Для историй массивов используется `numpy`; `np.diff(time_s) > 0`
проверяет порядок точек интегрирования.

Физические формулы и ограничения приведены в
[описании численного перелёта](../solar_transfer.md).
