# `mars_flight/config.py`

## Назначение

Модуль хранит входные параметры расчёта и коэффициенты перевода единиц.
Физические параметры задаются в СИ.

## Используемые средства Python

`@dataclass(frozen=True)` автоматически создаёт конструктор класса и
запрещает переназначать поля после создания объекта. Так один набор
параметров не может случайно измениться во время расчёта.

После работы автоматически созданного конструктора вызывается
`__post_init__()`. Во всех четырёх классах он запускает `validate()`, поэтому
недопустимый объект нельзя создать и передать следующим модулям.

Функция `math.isfinite()` отклоняет `NaN`, положительную и отрицательную
бесконечность. Обычного сравнения `value <= 0.0` для этого недостаточно,
потому что сравнения с `NaN` всегда ложны.

## Константы

| Имя | Смысл | Единица |
|---|---|---:|
| `SECONDS_PER_DAY` | число секунд в сутках | с/сут. |
| `METRES_PER_KILOMETRE` | число метров в километре | м/км |
| `METRES_PER_MILLION_KILOMETRES` | число метров в миллионе километров | м/(млн км) |
| `KILOGRAMS_PER_TONNE` | число килограммов в тонне | кг/т |
| `NEWTONS_PER_KILONEWTON` | число ньютонов в килоньютоне | Н/кН |
| `ASTRONOMICAL_UNIT_M` | астрономическая единица | м |
| `SUN_GRAVITATIONAL_PARAMETER_M3_S2` | гравитационный параметр Солнца | м³/с² |
| `EARTH_ORBIT_RADIUS_M` | радиус принятой орбиты Земли | м |
| `MARS_ORBIT_RADIUS_M` | радиус принятой орбиты Марса | м |
| `EARTH_GRAVITATIONAL_PARAMETER_M3_S2` | гравитационный параметр Земли | м³/с² |
| `EARTH_RADIUS_M` | средний радиус Земли | м |
| `STANDARD_GRAVITY_M_S2` | стандартное ускорение свободного падения | м/с² |

Константы с префиксом `ASCENT_` задают массу корабля, параметры двигателя,
ограничение перегрузки и настройки численного решения взлёта. Константы
`TRANSFER_` задают предел времени, шага и допуски интегрирования пассивного
перелёта. Константы `MARS_` описывают Марс, тягу посадочного двигателя,
допуски и настройки интегрирования посадки. Глобальные значения
сгруппированы в начале файла по этапам и назначению.

## `MissionParameters`

Неизменяемый набор входных параметров:

| Поле | Смысл | Единица |
|---|---|---:|
| `sun_gravitational_parameter_m3_s2` | гравитационный параметр Солнца | м³/с² |
| `earth_orbit_radius_m` | радиус орбиты Земли | м |
| `mars_orbit_radius_m` | радиус орбиты Марса | м |

Метод `validate()` проверяет, что значения конечны и положительны, а радиус
орбиты Марса больше радиуса орбиты Земли. Проверка автоматически выполняется
при создании объекта.

`DEFAULT_PARAMETERS` содержит параметры стандартного расчёта Земля — Марс.
Их используют и `HohmannTransfer`, и `SolarTransferModel`.

## `EarthAscentParameters`

Неизменяемый набор параметров вертикального взлёта:

| Поле | Смысл | Единица |
|---|---|---:|
| `earth_gravitational_parameter_m3_s2` | гравитационный параметр Земли | м³/с² |
| `earth_radius_m` | радиус Земли | м |
| `standard_gravity_m_s2` | стандартное ускорение для расчёта перегрузки | м/с² |
| `initial_mass_kg` | начальная масса корабля | кг |
| `dry_mass_kg` | масса корабля без топлива | кг |
| `exhaust_velocity_m_s` | эффективная скорость истечения | м/с |
| `maximum_thrust_n` | максимальная тяга | Н |
| `maximum_load_factor` | предельная перегрузка в единицах $g_0$ | безразмерная |
| `maximum_time_s` | предельное время расчёта | с |
| `maximum_step_s` | максимальный шаг интегрирования | с |
| `relative_tolerance` | относительная погрешность решателя | безразмерная |
| `position_absolute_tolerance_m` | абсолютная погрешность координаты | м |
| `velocity_absolute_tolerance_m_s` | абсолютная погрешность скорости | м/с |
| `mass_absolute_tolerance_kg` | абсолютная погрешность массы | кг |

При создании объекта проверяются конечность и положительность значений,
отношение начальной и сухой масс, настройки решателя и возможность отрыва от
поверхности. `DEFAULT_EARTH_ASCENT_PARAMETERS` содержит стандартный набор.
Сухая масса в нём равна 5 т и повторно используется при расчёте посадки;
масса после взлёта становится начальной массой марсианского участка.

## `TransferIntegrationParameters`

Неизменяемые настройки интегрирования солнечного участка:

| Поле | Смысл | Единица |
|---|---|---:|
| `maximum_time_s` | предельное время до противоположной стороны орбиты | с |
| `maximum_step_s` | максимальный шаг решателя | с |
| `relative_tolerance` | относительный допуск | безразмерная |
| `position_absolute_tolerance_m` | абсолютный допуск для `x` и `y` | м |
| `velocity_absolute_tolerance_m_s` | абсолютный допуск для `v_x` и `v_y` | м/с |

Все поля должны быть конечными и положительными; относительный допуск должен
быть меньше единицы, а максимальный шаг не может превышать предельное время.
Стандартный объект `DEFAULT_TRANSFER_INTEGRATION_PARAMETERS` задаёт 400 суток,
шаг не более четверти суток, `rtol=10⁻¹⁰`, допуски 1 м и 10⁻⁶ м/с.

## `MarsLandingParameters`

Неизменяемый набор физических параметров и настроек посадки:

| Поле | Смысл | Единица |
|---|---|---:|
| `mars_gravitational_parameter_m3_s2` | гравитационный параметр Марса | м³/с² |
| `mars_radius_m`, `initial_radius_m` | радиус Марса и начальное расстояние от его центра | м |
| `contact_altitude_tolerance_m` | допустимое отклонение точки остановки от поверхности | м |
| `dry_mass_kg` | масса без топлива | кг |
| `exhaust_velocity_m_s` | эффективная скорость истечения | м/с |
| `maximum_thrust_n`, `maximum_load_factor` | пределы тяги и перегрузки | Н, безразмерная |
| `standard_gravity_m_s2` | опорное ускорение для перегрузки | м/с² |
| `maximum_time_s` | предельное время снижения | с |
| `coast_maximum_step_s`, `burn_maximum_step_s` | максимальные шаги двух участков | с |
| `relative_tolerance` | относительный допуск решателя | безразмерная |
| `position_absolute_tolerance_m` | абсолютный допуск радиуса | м |
| `velocity_absolute_tolerance_m_s` | абсолютный допуск скорости | м/с |
| `mass_absolute_tolerance_kg` | абсолютный допуск массы | кг |

`validate()` требует конечных положительных значений, начального радиуса
больше радиуса Марса, относительного допуска меньше единицы и шагов не
больше предельного времени. `DEFAULT_MARS_LANDING_PARAMETERS` использует
общую сухую массу и скорость истечения, а радиус начального состояния
получает из приближения сферы влияния. Перед посадкой `mission.py`
проверяет радиальное расхождение с орбитой Марса по константе
`MARS_ORBIT_MATCH_TOLERANCE_M`.

Четыре объекта `DEFAULT_*` создаются при импорте модуля и проверяются до
начала расчёта. Физические допущения изложены в документах по
[перелёту](../solar_transfer.md) и [посадке](../mars_landing.md).
