# `mars_flight/config.py`

## Назначение

Модуль хранит входные параметры аналитической модели и коэффициенты
перевода единиц. Физические параметры задаются в СИ.

## Константы

| Имя | Смысл | Единица |
|---|---|---:|
| `SECONDS_PER_DAY` | число секунд в сутках | с/сут. |
| `METRES_PER_KILOMETRE` | число метров в километре | м/км |
| `METRES_PER_MILLION_KILOMETRES` | число метров в миллионе километров | м/(млн км) |
| `ASTRONOMICAL_UNIT_M` | астрономическая единица | м |
| `SUN_GRAVITATIONAL_PARAMETER_M3_S2` | гравитационный параметр Солнца | м³/с² |
| `EARTH_ORBIT_RADIUS_M` | радиус принятой орбиты Земли | м |
| `MARS_ORBIT_RADIUS_M` | радиус принятой орбиты Марса | м |

## `MissionParameters`

Неизменяемый набор входных параметров:

| Поле | Смысл | Единица |
|---|---|---:|
| `sun_gravitational_parameter_m3_s2` | гравитационный параметр Солнца | м³/с² |
| `earth_orbit_radius_m` | радиус орбиты Земли | м |
| `mars_orbit_radius_m` | радиус орбиты Марса | м |

Метод `validate()` проверяет, что значения конечны и положительны, а радиус
орбиты Марса больше радиуса орбиты Земли. Проверка автоматически выполняется
при создании объекта.

`DEFAULT_PARAMETERS` содержит параметры стандартного расчёта Земля — Марс.
