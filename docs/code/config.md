# `mars_flight/config.py`

## Назначение

Модуль хранит входные параметры расчёта и коэффициенты перевода единиц.
Физические параметры задаются в СИ.

## Используемые средства Python

`@dataclass(frozen=True)` автоматически создаёт конструктор класса и
запрещает переназначать поля после создания объекта. Так один набор
параметров не может случайно измениться во время расчёта.

После работы автоматически созданного конструктора вызывается
`__post_init__()`. В обоих классах он запускает `validate()`, поэтому
недопустимый объект нельзя создать и передать следующим модулям.

Функция `math.isfinite()` отклоняет `NaN`, положительную и отрицательную
бесконечность. Обычного сравнения `value <= 0.0` для этого недостаточно,
потому что сравнения с `NaN` всегда ложны.

## Константы

| Имя | Смысл | Единица |
|---|---|---:|
| `SECONDS_PER_DAY` | число секунд в сутках | с/сут. |
| `METRES_PER_KILOMETRE` | число метров в километре | м/км |
| `METRES_PER_MILLION_KILOMETRES` | число метров в миллионе километров | м/(млн км) |
| `KILOGRAMS_PER_TONNE` | число килограммов в тонне | кг/т |
| `ASTRONOMICAL_UNIT_M` | астрономическая единица | м |
| `SUN_GRAVITATIONAL_PARAMETER_M3_S2` | гравитационный параметр Солнца | м³/с² |
| `EARTH_ORBIT_RADIUS_M` | радиус принятой орбиты Земли | м |
| `MARS_ORBIT_RADIUS_M` | радиус принятой орбиты Марса | м |
| `EARTH_GRAVITATIONAL_PARAMETER_M3_S2` | гравитационный параметр Земли | м³/с² |
| `EARTH_RADIUS_M` | средний радиус Земли | м |
| `STANDARD_GRAVITY_M_S2` | стандартное ускорение свободного падения | м/с² |

Остальные константы с префиксом `ASCENT_` задают массу корабля, параметры
двигателя, ограничение перегрузки и настройки численного решения взлёта.

## `MissionParameters`

Неизменяемый набор входных параметров:

| Поле | Смысл | Единица |
|---|---|---:|
| `sun_gravitational_parameter_m3_s2` | гравитационный параметр Солнца | м³/с² |
| `earth_orbit_radius_m` | радиус орбиты Земли | м |
| `mars_orbit_radius_m` | радиус орбиты Марса | м |

Метод `validate()` проверяет, что значения конечны и положительны, а радиус
орбиты Марса больше радиуса орбиты Земли. Проверка автоматически выполняется
при создании объекта.

`DEFAULT_PARAMETERS` содержит параметры стандартного расчёта Земля — Марс.

## `EarthAscentParameters`

Неизменяемый набор параметров вертикального взлёта:

| Поле | Смысл | Единица |
|---|---|---:|
| `earth_gravitational_parameter_m3_s2` | гравитационный параметр Земли | м³/с² |
| `earth_radius_m` | радиус Земли | м |
| `standard_gravity_m_s2` | стандартное ускорение для расчёта перегрузки | м/с² |
| `initial_mass_kg` | начальная масса корабля | кг |
| `dry_mass_kg` | масса корабля без топлива | кг |
| `exhaust_velocity_m_s` | эффективная скорость истечения | м/с |
| `maximum_thrust_n` | максимальная тяга | Н |
| `maximum_load_factor` | предельная перегрузка в единицах $g_0$ | безразмерная |
| `maximum_time_s` | предельное время расчёта | с |
| `maximum_step_s` | максимальный шаг интегрирования | с |
| `relative_tolerance` | относительная погрешность решателя | безразмерная |
| `position_absolute_tolerance_m` | абсолютная погрешность координаты | м |
| `velocity_absolute_tolerance_m_s` | абсолютная погрешность скорости | м/с |
| `mass_absolute_tolerance_kg` | абсолютная погрешность массы | кг |

При создании объекта проверяются конечность и положительность значений,
отношение начальной и сухой масс, настройки решателя и возможность отрыва от
поверхности. `DEFAULT_EARTH_ASCENT_PARAMETERS` содержит стандартный набор.

Объекты `DEFAULT_PARAMETERS` и `DEFAULT_EARTH_ASCENT_PARAMETERS` создаются
при импорте модуля. Следовательно, их проверка выполняется до начала
основного расчёта.
