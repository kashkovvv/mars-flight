# `mars_flight/__main__.py`

## Назначение

Модуль является консольной точкой входа. Он рассчитывает переход Гомана,
передаёт требуемую скорость ухода модели взлёта и выводит результаты в
удобных единицах.

## Запуск

```bash
python -m mars_flight
```

## Порядок работы

1. Рассчитать параметры перехода через
   `HohmannTransfer.from_parameters()`.
2. Передать `departure_excess_speed_m_s` методу
   `EarthAscentModel.simulate()`.
3. Перевести результаты из СИ в удобные единицы.
4. Вывести параметры перехода и взлёта.

## Точка входа

Условие

```python
if __name__ == "__main__":
    main()
```

вызывает `main()` только при запуске `python -m mars_flight`. При импорте
модуля его функции определяются, но расчёт автоматически не запускается.

Преобразование из СИ выполняется только перед выводом. Объекты результатов
продолжают хранить исходные значения в СИ.

Физические формулы в этом модуле не реализуются. Они описаны в документации
[аналитического перехода](../hohmann_transfer.md) и
[вертикального взлёта](../earth_ascent.md).
