# `mars_flight/__main__.py`

## Назначение

Консольная точка входа последовательно запускает аналитический переход
Гомана, численный взлёт, пассивный перелёт и посадку на Марс. Единицы
СИ преобразуются только для вывода.

## Алгоритм

1. `HohmannTransfer.from_parameters()` определяет требуемую скорость
   ухода относительно Земли и аналитические ориентиры для перелёта.
2. `EarthAscentModel.simulate()` рассчитывает взлёт до этой энергии.
3. Из последнего значения `ascent.specific_energy_m2_s2` вычисляется
   **фактическая** скорость ухода `sqrt(2 * energy)`. Передача
   `ascent.final_radial_velocity_m_s` вместо неё была бы ошибкой:
   корабль ещё находится в земном гравитационном поле.
4. `SolarTransferModel.simulate()` получает скорость ухода относительно
   Земли и сам складывает её с орбитальной скоростью Земли для задания
   гелиоцентрического начального состояния.
5. Перед стыковкой с посадкой проверяется, что конечный радиус корабля
   отличается от принятого радиуса орбиты Марса не более чем на
   `MARS_ORBIT_MATCH_TOLERANCE_M`. Эта проверка касается радиуса, а не
   фактического положения планеты.
6. Из радиальной и касательной компонент скорости корабля и касательной
   скорости Марса функция `math.hypot()` вычисляет модуль скорости
   относительно Марса. `MarsLandingModel.simulate()` получает этот модуль
   и неизрасходованную на солнечном участке конечную массу взлёта.
7. Выводятся результаты всех этапов. Отрицательная аналитическая проекция
   скорости относительно Марса означает отставание корабля по направлению
   движения Марса; в посадку передаётся неотрицательный модуль вектора.

Перед пассивным участком проверяется положительность земной удельной энергии.
Если её нет или радиусы при стыковке с Марсом расходятся сверх допуска,
`main()` вызывает `RuntimeError`; ошибки численного интегрирования также не
скрываются.

## Смысл вывода

Аналитический блок содержит эталонные скорости и время Гомана.
Численный блок содержит время до противоположной стороны орбиты,
гелиоцентрический радиус и скорость корабля. Последняя строка выводит
**знаковую разность радиусов** корабля и орбиты Марса в этой точке.
Миллиметровое значение для стандартных параметров означает согласие
двух идеализированных расчётов при заданных допусках, а не точность
реального полёта к планете. Блок посадки выводит модуль скорости
относительно Марса, начальную высоту на границе принятой сферы влияния,
высоту включения двигателя, длительности снижения и торможения,
скорость контакта, остаточную массу и максимальную перегрузку.
Длительности солнечного и марсианского участков нельзя складывать для
получения точного времени миссии: их траектории не сшиты непрерывно.

Запуск:

```bash
python -m mars_flight
```

Условие `if __name__ == "__main__":` вызывает `main()` при таком запуске;
при импорте модуля расчёт не выполняется.
