# `mars_flight/__main__.py`

## Назначение

Модуль является консольной точкой входа. Он запускает аналитический расчёт,
переводит результаты из СИ в удобные единицы и выводит их на экран.

## Запуск

```bash
python -m mars_flight
```

## Порядок работы

1. Использовать `DEFAULT_PARAMETERS` из `config.py`.
2. Создать результат через `HohmannTransfer.from_parameters()`.
3. Перевести расстояние в миллионы километров, скорости в километры в
   секунду, время в сутки.
4. Вывести значения без изменения результата расчёта.

Физические формулы в этом модуле не реализуются. Их описание находится в
[документации аналитического расчёта](../hohmann_transfer.md).
