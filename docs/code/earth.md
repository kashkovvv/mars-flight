# `mars_flight/earth.py`

## Назначение

Модуль интегрирует вертикальный взлёт до требуемой энергии ухода из поля
Земли. Физические допущения, уравнения и критерий выключения двигателя
приведены в [теории взлёта](../earth_ascent.md).

## Результат и типы

`EarthAscentResult` — неизменяемый контейнер с историей расчёта в СИ.

| Поле | Смысл | Единица |
|---|---|---:|
| `time_s` | время | с |
| `radius_m` | расстояние до центра Земли | м |
| `altitude_m` | высота над поверхностью | м |
| `radial_velocity_m_s` | знаковая радиальная скорость, вверх положительно | м/с |
| `mass_kg` | текущая масса | кг |
| `thrust_n` | тяга земного двигателя | Н |
| `load_factor` | перегрузка от тяги в единицах стандартного $g_0$ | безразмерная |
| `specific_energy_m2_s2` | удельная энергия в поле Земли | м²/с² |
| `target_excess_speed_m_s` | заданный модуль скорости ухода вдали от Земли | м/с |

Свойства `duration_s`, `final_altitude_m`,
`final_radial_velocity_m_s`, `final_mass_kg` и
`maximum_load_factor` извлекают итоговые значения из массивов.

`NDArray[np.float64]` обозначает массив NumPy с вещественными элементами
двойной точности. Аннотация помогает статической проверке; фактический тип
задаёт `dtype=np.float64`. Метод `astype(np.float64, copy=False)` приводит
массивы решателя к этому типу и не создаёт копию, если преобразование не
нужно. Неизменяемость контейнера не делает вложенные массивы неизменяемыми.

## Модель и интегрирование

`EarthAscentModel` хранит проверенный объект `EarthAscentParameters`.
Метод `simulate(target_excess_speed_m_s)` возвращает результат или явно
сообщает о неудаче. Внутреннее состояние содержит радиус, знаковую радиальную
скорость и массу, именно в таком порядке. `_derivatives()` возвращает их
производные в том же порядке по уравнениям [теории](../earth_ascent.md).

`_thrust_n()` выбирает меньшую из максимальной тяги и тяги,
соответствующей пределу перегрузки; после достижения сухой массы тяга
нулевая. История `thrust_n` вычисляется по истории массы тем же законом
управления. Перегрузка `load_factor` равна `thrust_n / (mass_kg * g_0)`;
гравитационное ускорение в неё не входит.

`scipy.integrate.solve_ivp` численно решает начальную задачу. Здесь выбран
адаптивный метод `RK45`: оценки четвёртого и пятого порядков позволяют
уменьшать шаг, когда локальная ошибка велика, и увеличивать его в спокойной
области. `max_step` ограничивает шаг сверху. Относительный допуск
`rtol` безразмерен, а элементы `atol` имеют единицы соответствующих
состояний: метры, метры в секунду и килограммы. Масштаб проверки ошибки
компоненты приблизительно равен
`atol[i] + rtol * max(abs(y[i]), abs(y_new[i]))`.
Эти допуски контролируют численную, а не физическую погрешность модели.

## События и завершение

Вложенные функции `target_energy_event()` и `dry_mass_event()` возвращают
расстояние до соответствующей границы. Они получают время и массив
состояния, как требует `solve_ivp`. Замыкание даёт первой функции доступ к
целевой энергии и параметрам модели без временных полей объекта.

SciPy читает атрибуты `terminal` и `direction` самих функций.
`setattr()` устанавливает их без обращения к неописанным в типе функции
атрибутам: оба события терминальные, энергия пересекает ноль снизу вверх,
масса — сверху вниз. `solution.t_events[0]` содержит времена достижения
энергии, `solution.t_events[1]` — сухой массы. Код проверяет первый массив,
а при его пустоте использует второй для выбора сообщения об ошибке.

Алгоритм `simulate()`:

1. Проверить конечность и положительность целевой скорости и возможность
   вычислить её энергию без переполнения.
2. Сформировать начальное состояние, допуски и события.
3. Выполнить `solve_ivp`, проверить `solution.success` и `t_events`.
4. Из `solution.t` и `solution.y` получить историю состояния.
5. Вычислить высоту, тягу, перегрузку и удельную энергию; вернуть результат.

Недопустимая скорость вызывает `ValueError`. Неудача решателя, исчерпание
топлива и истечение времени до достижения цели вызывают `RuntimeError`;
их нельзя принять за успешный результат. Типы SciPy для `mypy`
предоставляет `scipy-stubs` из файла `requirements-dev.txt`.
