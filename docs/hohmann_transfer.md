# Аналитический перелёт Гомана

Перелёт Гомана используется как аналитический ориентир для проверки
численного движения корабля в поле Солнца.

## Допущения

- орбиты Земли и Марса круговые и лежат в одной плоскости;
- действует только притяжение Солнца;
- переходная орбита касается орбит Земли и Марса;
- изменение скорости при выходе на переходную орбиту считается мгновенным;
- начальное положение Марса не рассчитывается.

## Обозначения

| Обозначение | Смысл | Единица СИ |
|---|---|---:|
| $\mu_S$ | гравитационный параметр Солнца | $\text{м}^3/\text{с}^2$ |
| $r_E$ | радиус орбиты Земли | м |
| $r_M$ | радиус орбиты Марса | м |
| $a_t$ | большая полуось переходного эллипса | м |
| $v_E$ | скорость Земли относительно Солнца | м/с |
| $v_M$ | скорость Марса относительно Солнца | м/с |
| $v_{t,E}$ | скорость корабля на переходе у Земли | м/с |
| $v_{t,M}$ | скорость корабля на переходе у Марса | м/с |
| $v_{\infty,E}$ | скорость ухода относительно Земли | м/с |
| $v_{rel,M}$ | проекция скорости относительно Марса | м/с |
| $v_{encounter,M}$ | модуль скорости встречи с Марсом | м/с |
| $t_H$ | время перелёта | с |

## Расчёт

Ближайшая к Солнцу точка переходного эллипса находится на орбите Земли, а
самая далёкая — на орбите Марса. Поэтому его большая полуось равна

```math
a_t=\frac{r_E+r_M}{2}.
```

Для круговой орбиты гравитационное ускорение равно центростремительному:

```math
\frac{\mu_S}{r^2}=\frac{v_c^2}{r}.
```

Отсюда круговая скорость

```math
v_c(r)=\sqrt{\frac{\mu_S}{r}},
```

а скорости Земли и Марса равны

```math
v_E=\sqrt{\frac{\mu_S}{r_E}},
\qquad
v_M=\sqrt{\frac{\mu_S}{r_M}}.
```

Удельная механическая энергия в поле Солнца имеет вид

```math
\varepsilon=\frac{v^2}{2}-\frac{\mu_S}{r}.
```

Она получается делением полной энергии
$E=mv^2/2-\mu_Sm/r$ на массу корабля.

Для эллиптической орбиты она выражается через большую полуось:

```math
\varepsilon=-\frac{\mu_S}{2a}.
```

Эта связь следует из сохранения энергии и момента импульса. В ближайшей и
самой далёкой точках эллипса выполняются равенства

```math
r_pv_p=r_av_a,
```

```math
\frac{v_p^2}{2}-\frac{\mu_S}{r_p}
=
\frac{v_a^2}{2}-\frac{\mu_S}{r_a}.
```

Исключение $v_a$ даёт

```math
\varepsilon
=
-\frac{\mu_S}{r_p+r_a}
=
-\frac{\mu_S}{2a}.
```

Приравнивая два выражения для удельной энергии, получаем формулу вис-вива:

```math
v(r)
=
\sqrt{\mu_S\left(\frac{2}{r}-\frac{1}{a}\right)}.
```

Для переходного эллипса скорости у орбит Земли и Марса равны

```math
v_{t,E}
=
\sqrt{\mu_S\left(\frac{2}{r_E}-\frac{1}{a_t}\right)},
```

```math
v_{t,M}
=
\sqrt{\mu_S\left(\frac{2}{r_M}-\frac{1}{a_t}\right)}.
```

У Земли корабль и Земля движутся в одну сторону. Поэтому требуемая скорость
корабля относительно Земли после ухода из её поля равна

```math
v_{\infty,E}=v_{t,E}-v_E.
```

У Марса знаковая относительная скорость равна

```math
v_{rel,M}=v_{t,M}-v_M.
```

Для перелёта Гомана $v_{rel,M}<0$: Марс движется быстрее корабля и догоняет
его. Модуль скорости встречи равен

```math
v_{encounter,M}=|v_{rel,M}|.
```

Период эллиптической орбиты задаётся третьим законом Кеплера:

```math
T=2\pi\sqrt{\frac{a^3}{\mu_S}}.
```

Эта формула получается из постоянной секторной скорости $dA/dt=h/2$ и
площади эллипса $A=\pi ab$, где $h$ — удельный момент импульса, а $b$ —
малая полуось. Корабль проходит половину переходного эллипса, поэтому время
перелёта равно

```math
t_H=\frac{T}{2}
=
\pi\sqrt{\frac{a_t^3}{\mu_S}}.
```

## Проверки

Для перелёта от внутренней орбиты к внешней должны выполняться условия

```math
r_E<a_t<r_M,
```

```math
v_{t,E}>v_E,
\qquad
v_{t,M}<v_M.
```
