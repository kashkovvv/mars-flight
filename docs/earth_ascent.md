# Вертикальный взлёт с Земли

## Допущения

- движение происходит по прямой от центра Земли;
- Земля сферически симметрична;
- атмосфера и вращение Земли не учитываются;
- корабль описывается как одна ступень с эффективной скоростью истечения;
- тяга направлена вертикально вверх;
- двигатель выключается мгновенно при достижении требуемой энергии.

Такая модель позволяет исследовать влияние земного притяжения, расхода
топлива и ограничения перегрузки. Она не описывает реальную траекторию
ракеты-носителя со ступенями и наклонным участком полёта.

## Обозначения

| Обозначение | Смысл | Единица СИ |
|---|---|---:|
| $t$ | время от начала взлёта | с |
| $r$ | расстояние от центра Земли | м |
| $h=r-R_E$ | высота над поверхностью | м |
| $v$ | радиальная скорость, положительная вверх | м/с |
| $m$ | текущая масса корабля | кг |
| $R_E$ | радиус Земли | м |
| $\mu_E$ | гравитационный параметр Земли | м³/с² |
| $F$ | тяга двигателя | Н |
| $F_{\max}$ | максимальная тяга двигателя | Н |
| $u_e$ | эффективная скорость истечения | м/с |
| $g_0$ | стандартное ускорение свободного падения | м/с² |
| $n_{\max}$ | допустимая перегрузка в единицах $g_0$ | безразмерная |
| $v_{\infty,E}$ | требуемая остаточная скорость вдали от Земли | м/с |

## Уравнения движения

Ускорение земного притяжения на расстоянии $r$ от центра равно

```math
g_E(r)=\frac{\mu_E}{r^2}.
```

По второму закону Ньютона радиальное ускорение определяется тягой и
притяжением Земли:

```math
\frac{dv}{dt}=\frac{F}{m}-\frac{\mu_E}{r^2}.
```

Тяга связана с расходом массы и эффективной скоростью истечения соотношением
$F=-u_e\,dm/dt$. Поэтому система уравнений имеет вид

```math
\frac{dr}{dt}=v,
```

```math
\frac{dv}{dt}=\frac{F}{m}-\frac{\mu_E}{r^2},
```

```math
\frac{dm}{dt}=-\frac{F}{u_e}.
```

Величина $F/m$ — ускорение от тяги. Именно оно определяет ощущаемую
экипажем перегрузку:

```math
n=\frac{F}{m g_0}.
```

Например, $n=3$ означает ускорение от тяги
$3g_0\approx29{,}42\ \text{м}/\text{с}^2$, а не
$3\ \text{м}/\text{с}^2$.

Значение $n_{\max}=3$ не является расчётным пределом выживания человека.
Это параметр штатного длительного режима, принятый для стандартного
расчёта. Переносимость большей перегрузки зависит от её продолжительности,
направления относительно тела, положения экипажа и системы фиксации.

Для соблюдения ограничения тяга выбирается по закону

```math
F=\min\left(F_{\max},\;m n_{\max}g_0\right).
```

Пока масса велика, тяга может быть ограничена возможностями двигателя. При
уменьшении массы управление снижает тягу так, чтобы перегрузка не превышала
$n_{\max}$.

## Условие выключения двигателя

Удельная механическая энергия корабля в системе отсчёта Земли равна

```math
\varepsilon_E=\frac{v^2}{2}-\frac{\mu_E}{r}.
```

Для определения скорости ухода используется приближение сфер влияния:
после выключения двигателя рассматривается воображаемое движение только в
поле Земли. Его энергия сохраняется. Вдали от Земли потенциальная энергия
стремится к нулю, а скорость — к $v_{\infty,E}$. Поэтому требуемая энергия
равна

```math
\varepsilon_{\mathrm{target}}=\frac{v_{\infty,E}^2}{2}.
```

Это равенство совпадает с формулой для $v_{\infty,E}$ из общей
[математической модели](model.md). Условие выключения можно записать как

```math
\Phi(r,v)
=
\frac{v^2}{2}
-\frac{\mu_E}{r}
-\frac{v_{\infty,E}^2}{2}.
```

Двигатель выключается при $\Phi(r,v)=0$. Эквивалентная требуемая скорость на
текущем расстоянии имеет вид

```math
v_{target}(r)
=
\sqrt{v_{\infty,E}^2+\frac{2\mu_E}{r}}.
```

Поэтому скорость в конце активного участка не равна $v_{\infty,E}$: часть
кинетической энергии соответствовала бы последующему удалению от Земли. Это
удаление не рассчитывается как отдельный участок; оно заменяется
энергетическим пересчётом к $v_{\infty,E}$.

Начальные условия:

```math
r(0)=R_E,
\qquad
v(0)=0,
\qquad
m(0)=m_0.
```

Если масса достигает сухой массы раньше требуемой энергии, выбранных
параметров ракеты недостаточно для выполнения взлёта. В стандартном
расчёте сухая масса принята равной 5 т, поэтому после взлёта остаётся
топливо для [торможения на Марсе](mars_landing.md). Межпланетный участок
идёт без расхода топлива; изменение состава и ступеней корабля модель
не описывает.

## Аналитические проверки

Вывод начинается с двух уравнений используемой модели:

```math
\frac{dv}{dt}
=
\frac{F}{m}-\frac{\mu_E}{r^2},
```

```math
\frac{dm}{dt}=-\frac{F}{u_e}.
```

Из второго уравнения выражаем тягу:

```math
F=-u_e\frac{dm}{dt}.
```

Подставляем её в уравнение скорости:

```math
\frac{dv}{dt}
=
-\frac{u_e}{m}\frac{dm}{dt}
-
\frac{\mu_E}{r^2}.
```

Умножаем на $dt$:

```math
dv
=
-u_e\frac{dm}{m}
-
\frac{\mu_E}{r^2}\,dt.
```

Интегрируем от начального состояния $(v_0,m_0)$ до состояния
$(v(t),m(t))$:

```math
\int_{v_0}^{v(t)}dv
=
-u_e\int_{m_0}^{m(t)}\frac{dm}{m}
-
\int_0^t\frac{\mu_E}{r(\tau)^2}\,d\tau.
```

После вычисления интегралов по скорости и массе получаем

```math
v(t)-v_0
=
u_e\ln\frac{m_0}{m(t)}
-
\int_0^t\frac{\mu_E}{r(\tau)^2}\,d\tau.
```

В принятой модели $v_0=0$, поэтому

```math
v(t)
=
u_e\ln\frac{m_0}{m(t)}
-
\int_0^t\frac{\mu_E}{r(\tau)^2}\,d\tau.
```

Первое слагаемое — формула Циолковского для приращения скорости от расхода
топлива. Второе слагаемое — потери скорости на преодоление земного
притяжения. Если внешнее притяжение не учитывать, второе слагаемое исчезает
и остаётся обычная формула Циолковского:

```math
\Delta v
=
u_e\ln\frac{m_0}{m}.
```

Закон массы можно проверить отдельно. Пока $F=F_{\max}$,

```math
m(t)=m_0-\frac{F_{\max}}{u_e}t.
```

Переход к ограничению по перегрузке происходит при массе

```math
m_{\mathrm{switch}}=\frac{F_{\max}}{n_{\max}g_0}
```

в момент

```math
t_{\mathrm{switch}}
=
\frac{(m_0-m_{\mathrm{switch}})u_e}{F_{\max}}.
```

После этого $F=m n_{\max}g_0$, и масса убывает по закону

```math
m(t)
=
m_{\mathrm{switch}}
\exp\left(
-\frac{n_{\max}g_0}{u_e}(t-t_{\mathrm{switch}})
\right).
```

## Контрольные значения

Для стандартной конфигурации и
$v_{\infty,E}=2{,}9447\ \text{км}/\text{с}$ ожидаются значения:

| Величина | Значение |
|---|---:|
| продолжительность активного участка | 475,54 с |
| высота выключения двигателя | 2274,61 км |
| радиальная скорость при выключении | 10,044 км/с |
| конечная масса | 22,83 т |
| максимальная перегрузка | 3,00 $g$ |

Небольшие отличия возможны из-за округления
$v_{\infty,E}$ в этой таблице. В программе используется значение без
округления из аналитического расчёта перехода Гомана.

При начальной массе 500 т и конечной 22,83 т модель расходует около 95,4 %
начальной массы. Это эффективная одноступенчатая схема с заданной скоростью
истечения и управляемой тягой, а не проект реального носителя. Результат
показывает достижение требуемой энергии ухода в принятом приближении, но
сам по себе не означает прибытия к Марсу.
